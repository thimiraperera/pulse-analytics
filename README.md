# Pulse Analytics

Website statistics for WordPress that stay on your own server.

The plugin adds a Statistics page to the WordPress admin with visitors, pages, traffic sources, UTM campaigns, countries on a world map, devices, events, goals and a visitor log. Every report can be filtered and exported to CSV, and all reports can be downloaded together as a zip file. Visits are recorded by the site itself and stored in its own database. No cookies are used by default.

## Installation

Download `pulse-analytics.zip` from the [latest release](https://github.com/thimiraperera/pulse-analytics/releases/latest) and upload it in WordPress under Plugins > Add New > Upload Plugin.

Requires WordPress 6.0 or later and PHP 7.4 or later.

## Updates

New versions are published as releases in this repository and show up on the WordPress Plugins screen like any other plugin update.
